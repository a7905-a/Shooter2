## 3인칭 슈팅 게임 포트폴리오

+ InputSystem
  + 플레이어 이동
    + PlayerInput - Invoke Unity Events 사용
    + Invoke Unity Events는 스크립트 내 함수를 직접적으로 연결해서 오타 및 휴먼에러 방지 그리고 더 빠름 그래서 사용
  + 카메라 시점
    + Input System에서 마우스 델타 값(Vector2)을 받아 카메라의 회전 각도에 반영하는 방식으로 구현
  + CharacterController
    + 조작감과 실행되는 원리에 따라 Rigidbody 대신 CharacterController를 사용 
---
+ Enemy
  + 적 체력과 파괴
    1. 적 체력, 데미지 처리 데이터를 전담하는 EnemyHealth라는 스크립트 생성
    2. 플레이어 무기에서 EnemyHealth의 TakeDamage 함수만 호출 
  + 스폰
    1. 보이지 않는 스위치를 만들어 플레이어가 지나가면 OnTriggerEnter를 사용해 플레이어의 접근을 확인
    2. 스폰된 적을 다 없애면 다음 스테이지의 문이 개
---
+ 무기
  + 조준
    1. 마우스 우클릭 시 시네머신 카메라를 확대하고, 애니메이션 리깅을 통해 캐릭터와 상체의 시선이 조준점을 따라가도록 구현
  + 장착
    1. ScriptableObject 기반의 무기 데이터를 활용해서 교체 시 모델, 애니메이션의 레이어, .IK타겟을 재설정하는 장착 시스템 구현
  + 무기 획득
    1. 필드에 배치된 무기 아이템과 상호작용 시, 해당 무기의 데이터(SO)를 플레이어에게 전달하여 즉시 장착 및 사용
---
+ 기타 게임 매니저
  + 체력 바
    1. 월드 공간의 캔버스와 빌보드 기법을 활용하여, 카메라가 어느 방향에서 보든 항상 적의 머리 위에 고정되어 보이는 직관적인 UI를 구현
  + 풀링 매니저
    1. 이펙트 같은 빈번하게 생성, 파괴되는 오브젝트를 미리 생성해두고 재사용하는 오브젝트 풀링 시스템을 구축하여, 메모리 할당 비용을 줄이고 런타임 성능을 최적화
